Commands

The commands used across chapter 1 of Linux, Networking, Deployment & Cryptography, A to Z, with the options you will reach for most. Commands tagged Learn Linux TV have a video on that channel.

1. AppArmor

Is used to manage mandatory access control profiles

On its own aa-status already runs bare: it lists loaded profiles and their modes. The others need a profile.

1.1aa-status
Is used to list loaded profiles and their modes
1.2aa-enforce /etc/apparmor.d/<profile>
Is used to block what the profile forbids
1.3aa-complain /etc/apparmor.d/<profile>
Is used to only log what the profile forbids
1.4aa-disable /etc/apparmor.d/<profile>
Is used to unload a profile
1.5aa-genprof <program>
Is used to build a profile by watching the program run
1.6apparmor_parser -r /etc/apparmor.d/<profile>
Is used to reload after editing

4. chroot

Is used to run a program with a different directory as its root, the oldest form of isolation and the ancestor of containers

On its own Nothing. It stops with "missing operand": it needs a directory to use as the new root.

4.1chroot <dir>
Is used to start a shell inside it: $SHELL, or /bin/sh if that is unset, which must exist inside the new root
4.2debootstrap stable <dir>
Is used to build a Debian root filesystem to chroot into (Alpine's minirootfs tarball does the same in one download)
4.3cp /etc/resolv.conf <dir>/etc/
Is used to give it working DNS
4.4chroot <dir> /bin/sh -l
Is used to run a given program inside, here a login shell
4.5chroot --userspec=1000:1000 <dir> <cmd>
Is used to drop from root to another user once inside
4.6chroot --groups=wheel,video <dir> <cmd>
Is used to set the supplementary groups it runs with
4.7mount -t proc proc <dir>/proc
Is used to give it a /proc, so ps and top work inside
4.8ls -l /proc/<pid>/root
Is used to see which directory a process treats as its root
4.9systemd-nspawn -D <dir>
Is used to do the same with namespaces added, a chroot that is close to a container
4.10umount -R <dir>/{proc,sys,dev}
Is used to clean up the mounts afterwards
4.11mount --rbind /dev <dir>/dev && mount --rbind /sys <dir>/sys
Is used to pass the host's devices and /sys through, as when repairing a system that will not boot

8. dfLearn Linux TV

Is used to show how full each mounted filesystem is

On its own Lists each mounted filesystem with its size, used and available space in 1K blocks, the percentage used and where it is mounted. Pseudo filesystems such as /proc are left out unless you add -a.

8.1df -h
Is used to show sizes in K, M and G instead of blocks
8.2df -T
Is used to add a column with each filesystem's type
8.3df -i
Is used to show inodes instead of blocks: a disk with space left still refuses new files once they run out
8.4df -l
Is used to show only local filesystems, skipping network mounts
8.5df -h <path>
Is used to see which filesystem a path lives on and how much room is left there
8.6df -h --total
Is used to add a grand total line at the bottom
8.7df -h -t overlay
Is used to list only overlay mounts, one for each running container's root filesystem
8.8df -h -x tmpfs -x devtmpfs
Is used to hide filesystems held in memory, so only real disks are listed
8.9df -h --output=source,fstype,size,used,avail,pcent,target
Is used to choose which columns appear, and in what order

11. duLearn Linux TV

Is used to measure how much disk space files and directories take up

On its own Walks the current directory and prints the space used by every subdirectory, at every depth, in 1K blocks, with the total for . on the last line.

11.1du -sh <dir>
Is used to print one human-readable total for a directory
11.2du -sh *
Is used to total each item in the current directory (the glob skips hidden ones)
11.3du -h -d 1 <dir>
Is used to stop one level down, so you can see which subdirectory is big
11.4du -xh -d 1 /
Is used to stay on one filesystem, so /proc, /sys and other mounts are not counted
11.5du -h -d 1 <dir> | sort -h
Is used to list subdirectories from smallest to largest (sort -h understands K, M and G)
11.6du -ch *.log | tail -1
Is used to get the combined size of several files
11.7du -sh --apparent-size <file>
Is used to show the bytes a file holds rather than the blocks it uses, which differ for sparse files such as VM disk images
11.8du -sh --exclude='*.log' <dir>
Is used to leave matching files out of the count
11.9du -ah <dir> | sort -rh | head -20
Is used to find the 20 largest files and directories
11.10du -sh /var/lib/containerd/io.containerd.snapshotter.v1.overlayfs
Is used to see how much space unpacked image layers take
11.11lsof +L1
Is used to find deleted files that are still held open, the usual reason df reports more space used than du can find

16.18iptables -t nat -A PREROUTING -m statistic --mode random --probability 0.5 -j DNAT …
